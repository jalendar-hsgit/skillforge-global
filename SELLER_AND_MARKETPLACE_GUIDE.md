## 💼 SELLER API ENDPOINTS

### Mentor/Seller Profile
```bash
GET    /api/v1x/mentors
       Get all mentors/sellers

GET    /api/v1x/mentors/[id]
       Get specific mentor profile
       Example: /api/v1x/mentors/8

POST   /api/v1x/mentors
       Create mentor profile (requires User with MENTOR role)
```

### Marketplace Products (Seller's Products)
```bash
GET    /api/v1x/products
       List all products
       Query: ?seller_id=8

GET    /api/v1x/products/[id]
       Get product details

POST   /api/v1x/products
       Create new product (seller only)
       Body: {
         name: string,
         description: string,
         price: number,
         product_type: string,
         seller_id: number
       }

PUT    /api/v1x/products/[id]
       Update product (seller only)

DELETE /api/v1x/products/[id]
       Delete product (seller only)
```

### Seller Orders & Sales
```bash
GET    /api/v1x/orders
       Get orders (filters by user_id if student, shows orders of seller's products if mentor)

GET    /api/v1x/orders/[id]
       Get order details

POST   /api/v1x/orders
       Create order (student purchases product)
       Body: {
         user_id: number,
         course_id?: number,
         product_id?: number,
         amount: number,
         payment_method: string
       }
```

### Seller Payouts & Earnings
```bash
GET    /api/v1x/mentors/payouts/history
       View payout history
       Auth: Requires login as seller/mentor

GET    /api/v1x/mentors/sessions/my
       View mentor's sessions/bookings

POST   /api/v1x/mentors/sessions
       Create new session (receive booking)

GET    /api/v1x/mentors/earnings
       View earnings summary (if endpoint exists)
```

## 📞 SELLER SUPPORT

### Common Issues & Solutions

**Q: How do I get paid?**
```
A: Earnings are automatically transferred to your connected
   Stripe account based on your payout schedule.
   View details: API endpoint /api/v1x/mentors/payouts/history
```

**Q: When are payouts processed?**
```
A: Typically 1-5 business days depending on your bank.
   Payouts are triggered when minimum balance is reached.
```

**Q: How much commission does the platform take?**
```
A: 20% commission on all marketplace sales.
   You keep 80% of the product price.
```

**Q: Can I change product prices?**
```
A: Yes, update via API or dashboard (when available).
   Changes apply to future purchases.
```

**Q: Do I need tax documents?**
```
A: Yes, complete tax verification for payouts.
   Use: POST /api/v1x/mentors/verify/tax-info
```
